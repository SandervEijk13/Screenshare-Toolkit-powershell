# Screenshare Toolkit PowerShell

A PowerShell toolkit designed to assist with **screensharing, system checks, and cheat detection**.

## Features

* 🖥️ Screenshare assistance
* 🔍 System and process checks
* 🛡️ Cheat detection utilities
* ⚡ Quick PowerShell-based dashboard
* 📦 No manual installation required

## Usage

### 1. Open Command Prompt as Administrator

Right-click **Command Prompt** and select **Run as administrator**.

### 2. Run the Toolkit

Paste the following command into CMD:

```powershell
powershell -ExecutionPolicy Bypass -Command "Invoke-Expression (Invoke-RestMethod 'https://raw.githubusercontent.com/SandervEijk13/Screenshare-Toolkit-powershell/main/Dashboard.ps1')"
```

The toolkit will download and launch the latest `Dashboard.ps1` directly from this repository.

## Requirements

* Windows
* PowerShell
* Administrator privileges
* Internet connection
